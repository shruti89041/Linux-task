# DevOps Internship – Progressive Assessment
## Week 1: Linux Fundamentals

## Overview
This repository contains the solutions and documentation for the **Week 1 – Linux Fundamentals** assessment as part of the DevOps Internship program.

The objective of this assessment is to develop practical Linux administration skills including user management, permissions, process handling, storage analysis, log investigation, file processing, archiving, and shell configuration.
